# Исходники оформления

## Иконка сайта

Положите сюда `icon-source.png` — квадратный PNG, лучше 1024×1024, — и выполните:

```bash
npm run icons design/icon-source.png
```

Скрипт нарежет весь набор: вкладка браузера, экран «Домой» в iOS, две иконки
манифеста и маскируемую версию с полями под обрезку Android. Ссылки в `<head>`
Next проставит сам.

Требования к исходнику:

- квадрат, минимум 512×512;
- плоская заливка без градиентов, бликов и объёма — §7.1;
- рисунок читается в 16 пикселей: одна крупная форма, без мелких деталей;
- палитра из `src/styles/tokens.css`: графит `#14181E`, бумага `#FBFAF7`,
  латунь `#B8862B`;
- поля по краям около 12 % ширины, иначе маскируемая версия срежет края.

## Портреты персон

Портреты сюда класть не нужно — они принимаются напрямую:

```bash
npm run photo -- <slug> <файл> --author="…" --license="…" --source="…"
```

Скрипт кадрирует в 4:5, приводит к 1200×1500, применяет единую коррекцию
и прописывает снимок в файл персоны вместе с данными о правах. Без лицензии
проверка контента не пропустит публикацию: права на фотографию принадлежат
фотографу.
