# Контент

Источник правды по персонам, рубрикам и редакции. Файлы читаются на сборке
(`src/lib/content.ts`); после правки нужен перезапуск сборки.

## Как добавить персону

1. Создать `content/persons/<slug>.json`. **Имя файла обязано совпадать со слагом.**
2. Слаг — транслитерация имени по ГОСТ 7.79-2000 система Б (§4.1):
   «Андрей Мейстер» → `andrej-mejster`. Проверить можно так:
   `npx tsx -e "import{slugify}from'./src/lib/translit';console.log(slugify('Андрей Мейстер'))"`
3. Однофамильцы разводятся суффиксом сферы: `/ivan-ivanov/`, `/ivan-ivanov-yurist/`.
4. Прогнать `npm run check:content` — проверятся зарезервированные слова, рубрики,
   редактор, объём текста под тариф, полнота маркировки.

**Слаг после публикации не меняется.** Если менять всё же пришлось — добавить запись
в `content/redirects.json`; старый адрес остаётся навсегда и отдаёт 301, а не 404.

## Обязательные поля

Минимальный набор для публикации: `slug`, `full_name`, `display_name`, `name_latin`,
`tagline` (до 120 знаков), `lead` (до 600), `spheres` (1–3), `occupations`, `body`,
`photos`, `plan`, `status`, `editor`, `published_at`, `updated_at`.
Полный список — `src/lib/types.ts`.

- `status: "published"` — единственное значение, при котором персона видна снаружи.
- `verified: true` требует `verified_scope`: что именно проверено по документам.
  Ставить значок без проверки нельзя (§6.4).
- `erid` требует `advertiser` — иначе маркировка неполная (§11.4).
- Объём `body` под тариф: free ≤ 600, base 2 500–4 000, extended 6 000–10 000 знаков.
- Для тарифа `extended` блок `sources` обязателен (§5.3).

## Фотографии

Портреты кладутся в `public/media/` и указываются как `{"src": "/media/…", "portrait": true,
"width": 1200, "height": 1500}`. Соотношение 4:5, минимум 1200×1500 (§7.5).
Если портрета нет, страница показывает монограмму из инициалов — это штатное
поведение дизайн-системы, «серый силуэт» запрещён.

## Рейтинг

`content/rating.json` — результат пересчёта, руками не редактируется.
Пересчёт: `npm run rating` (читает `content/metrics.json`).
Для воспроизводимого прогона можно передать метку времени:
`npx tsx scripts/compute-rating.ts 2026-08-03T03:00:00+03:00`.

## Демонстрационный набор

Персоны в текущем наборе — вымышленные, для проверки вёрстки и витрин.
Реальные биографии публикуются только по регламенту §12: заявка → согласие →
интервью → фактчекинг → согласование → публикация. Проверка `check:content`
намеренно ругается на короткие тексты демо-персон: так видно, что лимиты работают.
