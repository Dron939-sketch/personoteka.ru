# Редакционный порядок персон: витрина главной и голова каталога.
#
# Файл используется дважды. На главной он задаёт блок «Выбор редакции».
# В каталоге при сортировке по умолчанию («по индексу внимания») эти персоны
# идут первыми в этом же порядке — потому что индекс пока нулевой у всех,
# и без ручной головы список открывается теми, кто просто раньше в алфавите.
#
# Блок «Выбор редакции» показывает персон ровно в этом порядке. Раньше на этом
# месте выводились восемь самых свежих биографий; свежие никуда не делись —
# они по ссылке «Все новые» рядом с заголовком.
#
# Почему список ручной, а не расчётный: витрина главной решает не ту задачу,
# что каталог. Каталогу нужна полнота и объективный порядок, главной — первое
# впечатление: разные сферы подряд, узнаваемые лица, хорошие портреты.
# Автоматика этого не даёт, пока рейтинг пуст и индекс внимания у всех нулевой.
#
# Правила: один слаг в строке, пустые строки и строки с # игнорируются.
# Несуществующий или неопубликованный слаг просто пропускается — витрина
# не должна ронять главную из-за опечатки.
